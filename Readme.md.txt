# 📈 Sales Forecasting Dashboard

A data analytics and forecasting project developed using Python and Power BI to analyze sales trends and predict future sales performance.

---

## 📊 Features

- Monthly sales trend analysis
- Forecasting future sales
- KPI metrics visualization
- Regional performance insights
- Interactive dashboard

---

## 🚀 Technologies Used

- Python
- Pandas
- Matplotlib
- Power BI
- Streamlit

---

## 📈 Analysis Workflow

- Data cleaning
- Time-series analysis
- Forecast generation
- Dashboard visualization
